# Ascend audit — 6 September 2026

Follow-up: the six confirmed defects were repaired after this audit. See [repair verification and remaining limits](AUDIT-FIXES-2026-09-06.md). The findings below preserve the original audit state.

**Verdict: the local app has working core features, but it is not fully reliable or ready for distribution.** Six issues are confirmed below. Most routine productivity workflows pass, existing encrypted history is readable, and a fresh two-hour recording transcribed successfully. Restarting transcription after cancellation failed in this audit. Passing unit tests do not override that runtime failure.

Audited checkout: `C:\Users\samar\Desktop\ascend`. Scope: implemented Electron shell, Python services, local Parakeet transcription, activity capture/accounting, encrypted storage/migrations, productivity expansion, and packaging configuration. This is an implementation audit, not a new feature delivery or release certification. Tests used isolated profiles and public/synthetic audio. No provider credentials or cloud transcription were used.

## Implemented limits and unfinished requests

- **Transcript autosave/library remains unbuilt**, despite the earlier request. Audio is processed locally; transcript text is held in memory until explicitly exported. Closing or clearing discards unsaved text.
- **Closing Ascend stops tracking.** Automatic start means opening Ascend, not Windows login. No tray/background persistence or login registration is implemented. Pause reminders require the app to remain open.
- Capture records the foreground app and its display, with optional window-title/accessibility checks. It does not understand everything visible across monitors. Browser URLs, page bodies, OCR and screenshots are absent.
- Coaching and habit observations are deterministic calculations, not an LLM or proof of cognitive attention. Recurring habits require at least three sufficiently observed days. The current saved history is too small for that baseline.
- Repeated app sequences produce conditional automation suggestions. They do not prove repeated task content, create an automation, or connect to another app.
- Dictation, meeting recording/notes, MCP/connectors, the in-product agent, full memory, and personal-life modules remain planned. Team administration and billing are outside the current personal scope.
- DPAPI protects saved activity for the current Windows account. Same-user access, process memory, paging and user-selected plaintext exports remain outside that protection. There is no portable backup/recovery feature.
