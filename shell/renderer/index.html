Your tracking, your choice.

Ascend starts when you sign into Windows and keeps running in the system tray when you close this window. A timed pause survives restarting.

Tracking resumes automatically. A countdown stays visible and a quiet desktop reminder repeats every 30 minutes, including in the tray. Windows notification settings may suppress desktop alerts.

Windows supplies these titles directly. UI Automation adds a separate safety check before any screenshot. Titles can contain sensitive information; filtering is best effort. Exclude a browser entirely if you need to guarantee its activity stays out.

Sonnet receives bounded app, window-title, UIA/domain, service, audio, and Haiku-result metadata. The separate Sonnet key never receives the screenshot.

Only the monitor containing the foreground window is captured. Eligible images are sent directly to Anthropic, analyzed into bounded activity evidence, and discarded from memory. Images are not saved by Ascend. Excluded and private windows are skipped. Maximum 1,440 screenshots per day.

Uses an already installed model through Ollama on this computer. Nothing is downloaded. In Review, preview the app/title and select Ask local AI. A suggestion changes nothing until you apply it. Cloud models are refused.

Remembered window-context rules

One executable name per line. Applies to future capture. Use Delete this day to remove existing history. Known password managers and detectable private windows are excluded automatically.

Saved approximately every 30 seconds and when paused or closed. An unexpected shutdown may lose the latest interval. Encrypted history is tied to your Windows account; it is not a portable backup.
